# Connect plugins to the workspace open in Mem

Install the current Nowledge Mem CLI on the computer **where the host runs**. These plugins require **nmem 0.10.126 or later**, with `nmem mcp --help` available. Ensure that the host can launch `nmem` on its PATH; a shell alias does not install an executable.

Codex, Cursor, WorkBuddy, CodeBuddy, Agent Plugins, Devin, DimAgent, Kimi Work, and the Craft Agent source example start `nmem mcp` over standard input and output. The same plugin setup works with the desktop backend and with a connected Cloud workspace. The CLI reads its selected endpoint and key when the host opens a session. After moving, start a new host session: the old one stays on its original workspace. Do not copy a key into a plugin manifest.

Custom remote servers and hosted connectors configured by URL are separate connections. If a host cannot run local commands (including a hosted install without the CLI), use its HTTPS connector settings instead. A plugin update does not rewrite your own MCP server definitions.

| Installation | How it gets the connection |
| --- | --- |
| Codex | Only the qualified `codex-workspace` marketplace ref delivers the stdio package. Unqualified marketplace updates retain the legacy 0.1.57 HTTP source. |
| Gemini CLI and ZCode | Their independently released native extensions use stdio. Update the extension on the computer running the host. |
| Claude Desktop and Kimi Code | Apply the stdio configuration generated by `nmem config mcp show --host claude-desktop` or `--host kimi-code`. Kimi Code's plugin manifest intentionally leaves MCP registration to the host. |
| DeepSeek Harness | The default uses stdio with the existing external-agent/slim profile. An explicitly set `NMEM_MCP_URL` still uses direct HTTP. |
| Dim and OpenHands | Both support stdio, but some existing installations intentionally use direct HTTP. Their package guides include a separate `mcp.stdio.json` for CLI-equipped installations without changing the default for existing remote/CLI-less setups. |
| MiniMax Code Local | The supported local configuration is a direct URL, not this bridge. This release does not add a MiniMax managed Cloud connector or establish a public URL reconnect flow. |

OpenClaw's REST hooks and Raycast's API preferences are not MCP manifest registrations.

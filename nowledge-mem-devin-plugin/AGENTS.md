# Nowledge Mem

Nowledge Mem is the user's cross-tool memory. For continuation, prior decisions,
preferences, regressions, or exact history, search Nowledge memories or Threads
before relying only on this Devin session. Use the bundled MCP tools first and
the `nmem` CLI only as a fallback.

At the beginning of substantial work, read the Context Bundle or Working Memory.
Save only durable decisions, procedures, preferences, and non-obvious learnings.
Do not turn transient progress, raw tool output, secrets, or guesses into Memory.

The lifecycle hooks synchronize Devin's own persisted conversation. They never
replace explicit Memory distillation. A Devin child session is a separate
Thread; do not flatten subagent conversation into its parent.
